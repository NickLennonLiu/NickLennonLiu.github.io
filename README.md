# Yuhe Liu Homepage

Static personal homepage for `NickLennonLiu.github.io`.

Preferred public URL: `https://river9.top/~liuyuhe/`.

The `CNAME` file can only contain a hostname, not a path. Do not set it to
`river9.top/~liuyuhe/`; GitHub Pages will reject or ignore that as an invalid
custom domain. Serving this site at `/~liuyuhe/` must be handled by the
`river9.top` web server or reverse proxy, for example by mounting these static
files under that path or by proxying `/~liuyuhe/` to the current Pages origin.

The blog is deployed separately from `NickLennonLiu/river-blog-deploy` and uses the custom domain `https://blog.river9.top/`. The local `/blog/` path redirects there because GitHub Pages project paths follow repository names; the `river-blog-deploy` repository would otherwise publish under `/river-blog-deploy/`.
